# BatStats

![バナー](fastlane/metadata/android/en-US/images/banner.svg)

BatStats は、Android が報告するバッテリー情報と、実際に観測した充放電の履歴を表示します。通常の情報は特権なしで利用できます。詳細統計には Shizuku、Root、または ADB による権限付与が必要です。取得できない値をゼロ消費として表示しません。

この開発ブランチは Android 16/API 36 を対象としています。実装と実際の検証状況は [PROGRESS.md](PROGRESS.md) と [検証記録](docs/VALIDATION.md) を参照してください。Samsung 実機での動作は未検証です。

## アクセスと数値の意味

Shizuku を起動し、アプリ内で BatStats を許可してください。実行中かつ許可済みの場合は Shizuku を優先します。切断後も通常の情報を利用できます。shell モードでは、Root 専用のカーネル情報まで読めるとは限りません。ADB の設定は [英語の説明](README.md#advanced-access) を参照してください。

- 観測期間は監視開始・リセット時からです。開始前や欠測区間の消費を推測して加算しません。
- 画面オフには非対話状態の常時表示（AOD）を含みます。画面オフ、CPU サスペンド、Android Doze は別の指標です。
- 電荷変化は Android の電荷カウンターに基づきます。電圧から算出するエネルギーや残り時間は推定で、機種や校正による違いがあります。
- アプリ別の mAh は Android の統計期間における推定電荷量であり、正確な電力量の実測値ではありません。同じ UID を共有するアプリの消費は正確に分離できません。長い動作時間や多い回数だけでは異常消費の原因を特定できません。

## 監視、履歴、インストール

詳細な監視通知は静かに更新されます。通常の読み取りは既定で30秒ごと、詳細統計は5分ごとです。短い間隔は応答性と処理負荷を増やします。実際の電池節約率は測定していません。アラートは監視中のみ動作し、音と振動は Android の通知設定で変更できます。

JSON/CSV の書き出しには単位、UTC 時刻、情報源、対象期間を含みます。履歴の削除は監視を停止しますが、Android のシステム統計はリセットしません。自動バックアップの対象は設定のみです。履歴は明示的に書き出してください。

スマートフォンからのビルド手順と署名の注意点は [ビルド・インストールガイド](docs/BUILD_AND_INSTALL.md) を参照してください。Preview は製品版と別のパッケージです。上書き更新には互換性のある署名が必要です。
